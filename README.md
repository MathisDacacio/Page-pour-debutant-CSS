# Projet HTML & CSS : Page pour Débutants

Ce projet est une introduction aux concepts HTML et CSS, combinant une structure HTML simple avec des styles CSS modernes et interactifs.

## Aperçu

Ce projet présente :
- Une liste d'objectifs
- Un formulaire de contact
- Une animation CSS personnalisée (un loader)
- Une illustration animée de machine à café créée avec du CSS pur
- Une explication de l'importance du CSS

L'objectif est d'aider les débutants à comprendre comment HTML et CSS interagissent pour créer des pages web dynamiques et esthétiques.

## Fonctionnalités

1. **HTML de base** : Structure simple avec des titres, paragraphes, listes et un formulaire.
2. **Styles avancés avec CSS** :
   - Animation d'un loader avec `loader.css`.
   - Illustration d'une machine à café animée avec `coffee.css`.
   - Personnalisation des couleurs et des tailles.
3. **Lien interactif** : Redirection vers un profil LinkedIn.
4. **Formulaire fonctionnel** : Permet la saisie d'informations utilisateur.

## Prérequis

- Un navigateur web moderne (Google Chrome, Firefox, Edge, etc.)
- Un éditeur de code (Visual Studio Code, Sublime Text, etc.) pour explorer ou modifier les fichiers.

## Voir le rendu

Pour afficher le rendu de ce projet :
1. Téléchargez les fichiers du projet sur votre ordinateur.
2. Assurez-vous que les fichiers `style.css`, `loader.css`, et `coffee.css` sont dans le même répertoire que le fichier HTML.
3. Ouvrez le fichier HTML dans un navigateur :
   - **Drag and drop** : Glissez le fichier HTML dans la fenêtre de votre navigateur.
   - **Double-clic** : Double-cliquez sur le fichier HTML depuis l'explorateur de fichiers.
